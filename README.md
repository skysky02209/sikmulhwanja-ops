# 식물환자 OPS — 온실 운영 관리

학교 온실 운영자를 위한 센서·측정 현황 대시보드 화면 시안입니다.

**라이브**: https://skysky02209.github.io/sikmulhwanja-ops/

## 이 화면이 무엇인가

여러 구역의 센서 상태와 재측정이 필요한 식물을 빠르게 확인하는 운영자용 화면입니다.
`데이터 품질` · `센서 상태` · `보정 만료` · `초음파 이벤트`를 각각 분리해 보여줍니다.

## 중요

- **모든 수치는 UI 데모 데이터입니다.** 실제 측정 결과가 아니며, 과학적으로 검증된 값이 아닙니다.
- 식물환자는 **식물 관리용 조기 점검 도구**입니다. 의료·농업 처방 시스템이 아닙니다.
- 초음파 측정만으로 병해나 원인을 확정하지 않습니다.
- 모든 식물 관련 알림은 `의심` · `재측정 필요` · `추가 점검 권장`까지만 표현합니다.

## 화면 상태

하단 전환 바에서 네 가지 상태를 볼 수 있습니다: `정상` · `로딩` · `데이터 없음` · `오류`

## 기술

- 단일 HTML 파일. 빌드 도구·외부 요청·CDN 없음
- 인라인 SVG 아이콘 (이모지 미사용)
- 데스크톱 우선, 768px 이하 단일 열 전환
- 다크모드 대응, 키보드 접근성, 색 외 기호·텍스트 병기
